git的ssh认证

Created in February 18, 2025

2025   ·   thirdYear_down   SEIII   git   ·   Skills

项目要求我们在git中的提交记录使用ssh签名来明确成员的工作情况. 之前没有使用过ssh, 所以搞了一段时间才搞定. 记录一下过程.

  • Step1

    创建ssh key. 这里是生成的一个ED25519:

    

    1

    		 
    ssh-keygen -t ed25519 -C "<your_email_address>"

    推荐就保存在它生成的默认位置~/.ssh. 带.pub后缀的是公共密钥.

  • Step2

    完成git中的ssh相关设置.

    

    1
2
3
4
5
6
7
8

    		 
    git config --global gpg.format ssh
git config --global user.signingkey ~/.ssh/your_ssh_key.pub
# 创建并写入allowed_signers文件,用于记录用户和公钥的对应关系
# 文件内容为 $(email) namespcaes="git" $(publicKey)
# 可以写在.git里配置一个项目,或者是像下面一样写在.ssh里作为全局配置
echo "$(git config --get user.email) namespaces=""git"" $(cat ~/.ssh/your_key.pub)" >> ~/.ssh/allowed_signers
dos2unix ~/.ssh/allowed_signers # win平台额外操作
git config --global gpg.ssh.allowedSignersFile "allowed_signers_path"

    并且在对应的git托管平台上将ssh key设置好.

  • Step3

    在commit中进行签名.

    通常地, 额外加入-S命令就是带签名的commit;

    可以进行全局设置而省去每次额外打字的麻烦:

    

    1

    		 
    git config --global commit.gpgsign true

  • extra

    如果发现git平台上的commit是带签名的,但是状态是"未验证", 那么说明签名的email和平台的email不一致, 改一下就行了.
